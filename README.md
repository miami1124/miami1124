## 關於我

我的起點通常是一句抱怨——「這件事我已經做第三次了，能不能讓電腦自己做？」

把抱怨拆成流程，跟 AI 一起開發、測試，再拿回去給真正的使用者用。判斷做完沒有的標準只有一個——**有沒有人每天願意打開它。**

現在專門研究怎麼把 AI 帶進工作流程，讓不同部門少做一點重複的事。
